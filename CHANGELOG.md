# Список изменений

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
проект придерживается [семантического версионирования](https://semver.org/lang/ru/).

## [Не выпущено]

### Добавлено

- Проверка доступности Wildberries с текущего IP при запуске `tracker.py`.
  При старте выполняется лёгкий запрос к `card.wb.ru`; если WB недоступен,
  в лог пишется понятное предупреждение с вероятной причиной.
- Флаг `--skip-wb-check` — отключает стартовую проверку доступности WB.
- Подсказка при ответе `403` от WB: обычно это блок по IP (зарубежный или
  датацентровый адрес, VPS/хостинг). В сообщении — как проверить IP
  (`curl -s https://ipinfo.io/json`) и варианты решения (резидентный прокси
  или российский IP).
- Файл `CHANGELOG.md` со списком изменений проекта.

### Изменено

- Запуск не прерывается при недоступном WB: выводится предупреждение,
  процесс продолжает работу (чтобы бот всё равно поднялся).

## [0.1.0] — 2026-XX-XX

### Добавлено

- Базовый трекер цен Wildberries с уведомлениями в Telegram.
- Режимы запуска: разовая проверка, `--watch` (цикл), `--bot` (Telegram-бот).
- Команды бота: `/prices`, `/list`, `/add`, `/del`, `/help`.
- Хранение состояния цен в `data/prices.json`, товары — в `config.json`.
- Привязка товара к пользователю (`owner_chat_id`): уведомления приходят
  только тому, кто добавил товар.
